# 云策计划 Agents 监控看板

🚀 实时监控云策计划Agents团队的机器人任务执行情况

## 📊 功能特性

- **实时统计**：任务总数、执行中任务、异常任务、在线机器人
- **任务分析**：7日趋势、类型分布、状态分布、完成率分析
- **Agent管理**：点击机器人查看专属任务，显示汇总统计
- **协同分析**：TOP5发起人排行榜
- **赛博朋克风格**：霓虹色彩、发光效果、动画交互

## 🎨 设计风格

- 深色主题 + 霓虹配色（青色、紫色、绿色、黄色、粉色）
- 毛玻璃效果（backdrop-filter: blur）
- 动画交互（扫描线、呼吸灯、悬停效果）
- 响应式布局

## 📦 技术栈

- 纯前端（HTML + CSS + JavaScript）
- Chart.js 4.4.0（数据可视化）
- Google Fonts（Orbitron、Rajdhani、JetBrains Mono）

## 🔧 本地使用

1. 打开 `index.html` 即可直接在浏览器中使用
2. 或使用本地服务器：
   ```bash
   python -m http.server 8000
   # 访问 http://localhost:8000
   ```

## 🌐 数据更新

修改 `data.json` 文件来更新看板数据：
- `stats`：总体统计数据
- `agents`：机器人列表
- `tasks`：任务明细
- `analytics`：分析数据（发起人TOP5、趋势等）

## 📝 部署到 GitHub Pages

1. 创建 GitHub 仓库（Public）
2. 关联并推送代码：
   ```bash
   git remote add origin https://github.com/你的用户名/仓库名.git
   git push -u origin main
   ```
3. 仓库设置 → Pages → Source 选择 `main` 分支
4. 访问 `https://你的用户名.github.io/仓库名/`
